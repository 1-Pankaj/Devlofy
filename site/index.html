01 The product

Three rooms,
one desk.

Every screen reads the same database. No sync step, no export dance, no second copy to keep in step with the first.

01 Today

The day, already sorted.

Type one line: Ship the invoice fix !3 45m tomorrow #Northwind. The tokens become priority, estimate, due date and project. The rest stays the title. Today shows the task it will create before you commit to it, then ranks what is left and prints the reason for every score.

  • Quick add parses as you type, with a preview of the saved task.
  • Next-up weighs overdue, due today, priority and effort. It says why.
  • A focus block writes to the session log, attributed to its project.

02 The ledger

The invoice was already written.

A block is marked billable when it starts, at the project's rate, falling back to the client's. The invoice is a view over the session log, never a stored document. Change a rate and the total follows. Delete a block and its line goes with it. 2h 40m at ₹2,500/h is ₹6,666.67, and every rupee traces to a session.

  • The rate lives on the project, with the client as the fallback.
  • Billable at the start of a block, not reconstructed afterwards.
  • Totals are a query. There is no second invoice to keep in sync.

03 Bench

Eleven tools. No tab.

JSON, SQL, diff, regex, text, base64, JWT, SHA-256, timestamps, cron and colour. Each one computes while you type, offline, with no Run button and no stale result to read. The hash tool is checked against the published vectors, and the diff renderer is the same one the GitHub editor uses.

  • Eleven tools across data, text, security, time and design.
  • No network, no dependency, and no half-parsed YAML.
  • A kept snippet reopens inside the tool that made it.

04 The garden

Hours in.
Canopy out.

The tree is built from your focus history, not a streak counter. Five stages, from seed to canopy, weighted by the minutes you actually worked. Miss a week and nothing wilts.

What grows it

Focus minutes 55%
Streak 30%
Today 15%

Weighted by growthFromStats(). No penalty state, no dead plant.

  • Five Blender-authored stages, with a procedural fallback.
  • Eleven authored GLB props; the bench and signpost are built in code.
  • One hanging plate per active project, up to five.

07 Questions

The honest
answers.

Including the parts that are not finished. If a claim is not in the repository, it is not on this page.

Still unanswered? Open an issue (opens in a new tab)

Is there a download?

Not yet. v0.8.0 has no APK and no store listing, so this page does not offer one. Clone the repository and run it with Expo. A signed build is a later step, not part of this release.

Does it need an account or a connection?

No Devlofy account and no backend. Everything works offline except GitHub and Sentinel, which make requests only when you open them. Your data is one SQLite file on the device.

Is there any cloud AI?

No. The Engine is a documented weight table and a set of pure functions over your own rows. Every score prints a reason you can read, disagree with and change.

What happens if I miss a day?

Nothing wilts. Growth is 55% focus minutes, 30% streak and 15% today, so a gap slows the tree rather than killing it. Trophies come from real history, not from a counter you have to protect.

Can I get my data out?

Yes. exportAll() writes a JSON dump of every table you own, with a format version. On Android the database file is yours to copy, back up or delete without asking; on the web, the export is the way out.

Why Android and web?

The app is personal-first. A phone gets the tab bar; a desktop-width screen gets a side rail. Both are in scope. iOS is kept iOS-safe in the code, but it is not a tested platform yet.

What is deliberately missing?

Background checks, notifications, sync, an iOS build and a store release. Each one has a written reason; sync is a decision, not a missing screen. Sentinel checks while you look, and says exactly that.

Your work is already yours.

No account to create. Nothing to migrate. Clone it, run it, and every row stays on your machine.
